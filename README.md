# SecureTrack SL - Mobile Applications & Backend

Automated Smart Container Monitoring and Tracking System for Sri Lanka Logistics & Port Authority.

## Project Structure
- `owner/` - Flutter Mobile Application for Fleet Owners & Cargo Tracking
- `driver_inspector/` - Flutter Mobile Application for Container Truck Drivers and Port Inspectors
- `backend/` - Shared Node.js REST API backend server
- `database/` - MySQL / XAMPP Database schema (`database_xampp.sql`)
